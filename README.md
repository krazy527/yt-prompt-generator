# 🎬 YouTube Prompt Generator

An AI-powered YouTube content assistant that helps creators generate high-quality thumbnail prompts, video titles, descriptions, and tags in seconds.

## 🚀 Live Demo

https://yt-prompt-generator.onrender.com/

## ✨ Features

* 🖼️ AI Thumbnail Prompt Generator
* 📝 YouTube Title Generator
* 📄 Video Description Generator
* 🏷️ SEO-Friendly Tags Generator
* ⚡ Fast AI-Powered Content Creation
* 📱 Fully Responsive UI
* 📋 One-Click Copy Functionality

## ⚙️ Installation

```bash
git clone https://github.com/krazy527/yt-prompt-generator.git
cd yt-prompt-generator
npm install
```

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key
```

Run the project:

```bash
npm run dev
```
